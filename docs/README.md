# Bộ tài liệu hiện hành

Đọc [RESEARCH_STATE](RESEARCH_STATE.md) -> [NEXT_EXPERIMENTS](NEXT_EXPERIMENTS.md) -> [POTENTIAL_DIRECTIONS](POTENTIAL_DIRECTIONS.md). [DATA_AND_REPRODUCIBILITY](DATA_AND_REPRODUCIBILITY.md) giải thích archive import/data/commands; [SOURCES](SOURCES.md) là prior-art bắt buộc.

Original v1/v2 packages không bị dọn vì cần tái lập/hashes. Root handoff logs/plans/prompts cũ chuyển sang [archive](../archive/README.md); không còn là thứ tự công việc mới.
